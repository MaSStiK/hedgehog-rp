# Hedgehog RP (Next.js)
> **Версия:** `v2.0.0`  
> **Старая версия (React):** [hedgehog-rp-legacy](https://github.com/MaSStiK/hedgehog-rp-legacy)

**Hedgehog RP** - социальная платформа для политической ролевой игры. Создайте собственное государство, развивайте его в соответствии со своими интересами, взаимодействуйте с другими участниками, заключайте союзы, ведите дипломатические переговоры или соперничайте за влияние на мировой арене.

Проект разрабатывается на **Next.js** для высокой производительности, удобного взаимодействия и расширяемости.  
Разработка проекта временно приостановлена в связи с потерей интереса и активности сообщества.

## ✨ Возможности
- Создание и развитие собственных государств
- Публикация новостей и внутриигровых событий
- Удобный редактор статей и постов
- Взаимодействие с другими участниками проекта
- Дипломатия, союзы и международные отношения
- Каталог участников и игровых государств
- Персональные профили пользователей и стран
- Лента новостей с актуальными публикациями сообщества
- Общая виртуальная вселенная с единой историей развития

## 🛠️ Технологии
- **Next.js** - основа приложения и роутинг
- **React** - интерфейс приложения
- **Axios** - выполнение HTTP-запросов
- **clsx** - объединение CSS-классов
- **Jotai** - управление состоянием приложения
- **jsonwebtoken** - работа с JWT-токенами
- **lucide-react** - набор SVG-иконок
- **Moment.js** - работа с датой и временем
- **MongoDB** - база данных проекта
- **Mongoose** - ODM для работы с MongoDB
