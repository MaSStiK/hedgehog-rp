# Hedgehog RP (Next.js)

</div>

> **Версия:** `v2.0.0`  
> **Предыдущая версия (React):** [hedgehog-rp-legacy](https://github.com/MaSStiK/hedgehog-rp-legacy)

**Hedgehog RP** - социальная платформа для политической ролевой игры в общем виртуальном мире. Участники могут создавать и развивать собственные государства, формируя политические и экономические системы в соответствии со своими интересами. Они публикуют новости, взаимодействуют с другими игроками, заключают союзы, ведут дипломатические переговоры, соперничают за влияние на мировой арене и участвуют в создании общей истории проекта.

Проект разрабатывается на **Next.js** с упором на высокую производительность, удобство использования и возможность расширять и масштабировать проект в долгосрочной перспективе.

> [!IMPORTANT]
> Разработка проекта заморожена из-за снижения интереса и активности сообщества.

## ✨ Возможности

- Создание и развитие собственных государств
- Публикация новостей и внутриигровых событий
- Удобный редактор статей и постов
- Взаимодействие с другими участниками сообщества
- Дипломатия, союзы и международные отношения
- Каталог игроков и государств
- Персональные профили пользователей и государств
- Лента новостей с актуальными публикациями сообщества
- Общий виртуальный мир с развивающейся историей

## 🛠️ Технологии

- **Next.js** - основа приложения и маршрутизация
- **React** - пользовательский интерфейс
- **Axios** - HTTP-запросы
- **clsx** - условное объединение CSS-классов
- **Jotai** - управление состоянием приложения
- **jsonwebtoken** - работа с JWT
- **lucide-react** - библиотека SVG-иконок
- **Moment.js** - работа с датой и временем
- **MongoDB** - база данных проекта
- **Mongoose** - ODM для MongoDB
