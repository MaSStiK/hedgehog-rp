# Hedgehog RP (Next.js)

> **Версия:** `v2.0.0`  
> **Старая версия (React):** [hedgehog-rp-legacy](https://github.com/MaSStiK/hedgehog-rp-legacy)

**Hedgehog RP (Legacy)** - социальная платформа для политической ролевой игры. Создайте собственное государство, развивайте его в соответствии со своими интересами, взаимодействуйте с другими участниками, заключайте союзы, ведите дипломатические переговоры или соперничайте за влияние на мировой арене.  
Проект разрабатывается на **Next.js** для высокой производительности, удобного взаимодействия и расширяемости.  
Разработка проекта временно приостановлена в связи с потерей интереса и активности сообщества.
