# Hedgehog RP (Next.js)

</div>

> **Version:** `v2.0.0`  
> **Legacy version (React):** [hedgehog-rp-legacy](https://github.com/MaSStiK/hedgehog-rp-legacy)

**Hedgehog RP** is a social platform for a political role-playing game set in a shared virtual world. Participants can create and develop their own countries, shaping political and economic systems according to their interests. They publish news, interact with other players, form alliances, engage in diplomatic negotiations, compete for influence on the world stage, and contribute to the project's shared history.

The project is developed with **Next.js** to support high performance, a smooth user experience, and an architecture that can be extended and scaled over time.

> [!IMPORTANT]
> Project development is on hold due to declining community interest and activity.

## ✨ Features

- Creation and development of your own countries
- Publication of news and in-game events
- User-friendly editor for articles and posts
- Interaction with other community members
- Diplomacy, alliances, and international relations
- Directory of players and countries
- Individual profiles for users and countries
- News feed with the latest community publications
- Shared virtual world with an evolving history

## 🛠️ Technologies

- **Next.js** - Application framework and routing
- **React** - User interface
- **Axios** - HTTP requests
- **clsx** - Conditional CSS class composition
- **Jotai** - Application state management
- **jsonwebtoken** - JWT handling
- **lucide-react** - SVG icon library
- **Moment.js** - Date and time handling
- **MongoDB** - Project database
- **Mongoose** - ODM for MongoDB
