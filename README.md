# Hedgehog RP (Next.js)
> **Version:** `v2.0.0`  
> **Legacy Version (React):** [hedgehog-rp-legacy](https://github.com/MaSStiK/hedgehog-rp-legacy)

**Hedgehog RP** is a social platform for a political role-playing game that brings participants together in a shared virtual world. Users can create their own countries, develop political and economic systems, publish news, interact with other players, form alliances, engage in diplomacy, and shape the ongoing history of the project.

The project is built with **Next.js** to provide high performance, a smooth user experience, and long-term scalability.  
Development is currently paused due to declining community activity and interest.

## ✨ Features
- Create and develop your own countries
- Publish news articles and in-game events
- User-friendly article and post editor
- Interact with other community members
- Diplomacy, alliances, and international relations
- Directory of players and countries
- Dedicated profiles for users and nations
- News feed with the latest community publications
- Shared virtual world with an evolving history

## 🛠️ Technologies

- **Next.js** - Application framework and routing
- **React** - User interface
- **Axios** - HTTP requests
- **clsx** - Conditional CSS class composition
- **Jotai** - State management
- **jsonwebtoken** - JWT token handling
- **lucide-react** - SVG icon library
- **Moment.js** - Date and time manipulation
- **MongoDB** - Project database
- **Mongoose** - ODM for MongoDB
