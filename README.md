# Hedgehog RP (Next.js)

> **Версия:** `v2.0.0`  
> **Старая версия (React):** [hedgehog-rp-legacy](https://github.com/MaSStiK/hedgehog-rp-legacy)

**Hedgehog RP (Legacy)** - социальная платформа для политической ролевой игры. Создайте своё государство, управляйте его развитием, взаимодействуйте с другими странами и ведите свою нацию к процветанию или мировому господству.  
Проект разработан на **Next.js** для высокой производительности, удобного взаимодействия и расширяемости.
Разработка проекта временно приостановлена в связи с потерей интереса и активности сообщества.
